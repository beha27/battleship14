# ⚔️ Морской Бой 10×10 (PvP & PvE)

Современная, стильная и полностью автономная веб-игра **«Морской Бой»**. Работает прямо в браузере без установки дополнительных программ и внешних серверов.

---

## 🚀 Особенности проекта

- **🤖 PvE (Игра с ботом):** Одиночный режим с искусственным интеллектом для быстрого старта.
- **👥 PvP (Дуэль с другом):** Игра для двоих с разных устройств (ПК, смартфонов или планшетов) через интернет или по локальной сети Wi-Fi с помощью технологии PeerJS.
- **🔊 Озвучка Web Audio API:** Динамическая генерация звуков выстрелов, попаданий и промахов прямо в браузере.
- **🎨 Tailwind CSS:** Красивый адаптивный интерфейс в тёмных тонах.

---

## 🎮 Как играть по сети (PvP)

1. Откройте игру (`index.html`) на двух разных устройствах.
2. **Первый игрок** нажимает кнопку **«👥 Играть с Другом (PvP)»** и видит свой сгенерированный **ID комнаты**.
3. Первый игрок передает этот ID второму игроку.
4. **Второй игрок** на своем устройстве нажимает ту же кнопку, вставляет полученный ID в поле ввода и нажимает **«Подключиться»**.
5. После успешного соединения в панели статуса появится сообщение о подключении.
6. Оба игрока нажимают **«🎲 Авто-расстановка»**, а затем **«🚀 В БОЙ!»** — как только оба подтвердят готовность, начнется сражение!

## 🌐 Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда файлы `index.html` и `README.md`.
2. Перейдите в настройки репозитория (**Settings**) -> раздел **Pages**.
3. В блоке **Branch** выберите ветку `main` (или `master`) и нажмите **Save**.
4. Игра станет доступна по ссылке, которую сгенерирует GitHub.
